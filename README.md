# 🏥 MediCalc Pro — Guide de Calculs Médicaux Rapides

Application web de calculs médicaux pour les professionnels de santé.  
**100% côté navigateur — Aucune donnée transmise à un serveur.**

---

## 🧮 Calculateurs inclus

### 📏 Mensurations
- IMC (Indice de Masse Corporelle) + Poids Idéal (Lorentz)
- Surface Corporelle (BSA — Mosteller)
- Pression Artérielle Moyenne (PAM)
- Index Cardio-Thoracique (ICT)

### 🧠 Neurologie
- Score de Glasgow (GCS)
- NIHSS simplifié

### 💊 Pharmacologie
- Doses Pédiatriques (avec médicaments pré-enregistrés)
- Débit de Perfusion

### 🫁 Pneumologie
- Score CURB-65 (Pneumonie)
- Score de Wells (TVP)

### ⚠️ Scores de Gravité
- Quick SOFA (Sepsis)

### 🔬 Rénal & Métabolique
- Clairance Créatinine (Cockcroft & Gault)
- Trou Anionique
- Calcémie Corrigée

### 👶 Pédiatrie
- Score d'APGAR

---

## 🚀 Déploiement sur GitHub Pages

1. **Forkez** ou **clonez** ce dépôt
2. Allez dans `Settings` → `Pages`
3. Sélectionnez la branche `main` (ou `master`)
4. Cliquez sur `Save`
5. Votre site sera disponible à : `https://[votre-username].github.io/medical-calc/`

---

## ⚠️ Avertissement

**Cet outil est une aide au calcul uniquement.**  
Il ne remplace pas le jugement clinique d'un médecin.  
**Vérifiez toujours les doses et les scores avant toute décision médicale.**
